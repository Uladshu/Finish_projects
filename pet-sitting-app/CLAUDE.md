# Индекс проекта: соцсеть помощи для владельцев животных

**Суть:** бесплатная локальная соцсеть для владельцев любых животных (потерялся/нашёлся, просьбы о помощи,
отдам/приму, группы по видам, опасности, карта ветклиник). Присмотр сначала как просьба о помощи, затем модуль
в стиле BlaBlaCar. **Старт:** Польша → Вроцлав → один район (вокруг Park Szczytnicki). Название не выбрано (в прототипе рабочее «Łapka Sąsiedzka»).

## Как работать
1. Найти нужный файл по таблице ниже → читать только его.
2. Новая идея → строка в `docs/ideas.md`. Принятое решение → строка в `docs/decisions.md`.
3. Изменил/добавил файл → обновить его строку в этой таблице (одна строка на файл).
4. SQL не читать целиком: карта объектов — `docs/tech/db.md`, код — через `grep -n`.
5. Источники ссылок — `docs/sources.md` (добавлять туда, в тематических файлах не дублировать).
