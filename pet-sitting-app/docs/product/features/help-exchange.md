# Функции: Помощь и обмен

Приоритет: **Запуск** — в первой версии · **Далее** — через 1–3 мес. · **Потом** — когда есть аудитория · **Нет** — не делаем.

| Функция | Откуда | Приоритет |
|---|---|---|
| **Просьба о помощи**: присмотр, покормить, выгулять, подвезти, купить лекарство | Nextdoor, BorrowMyDoggy | **Запуск** |
| **«Отдам / приму»**: корм, переноски, клетки, аквариумы, лекарства с неистёкшим сроком | OLX «за даром», группы FB | **Запуск** (очень частая нужда) |
| **Обмен у аквариумистов**: мальки, отводки растений, улитки; у террариумистов — корм (насекомые) | акваклубы, Reef2Reef, MorphMarket | Далее |
| «Друг животных» — люди без питомца бесплатно гуляют и помогают | BorrowMyDoggy | Далее |
| Баллы взаимопомощи («лапки») | банки времени | Потом |
| Адопция из приютов района | Petfinder, Befriend (Вроцлав) | Далее (партнёрство) |
