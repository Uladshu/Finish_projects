# Функции: баллы, уровни, медали

Приоритет: **Запуск** (базово, уже в прототипе) · рейтинг районов — Далее.

**Принцип:** баллы («łapki / лапки») только за **подтверждённые** действия; за количество постов не начисляются
(иначе спам и фейковые объявления о потерях). Без давящих механик: нет штрафов за пропуск дней, нет платных баллов.

| Действие | Баллы | Кто подтверждает |
|---|---|---|
| Помог найти животное | +100 | Владелец («Нашёлся благодаря …») |
| Помощь соседу (присмотр, выгул, подвёз) | +30 | Тот, кому помогли |
| Проверка аккаунта | +20 | Система |
| «Видел здесь» по потерявшемуся | +10 | Автоматически; модерация при жалобах |
| Подтверждение опасности | +5 | Совпадение с другими отметками |
| Объявление | +5 | Только первые N в месяц |
| Вступление в группу | +2 | Разово на группу |

**Уровни:** 0 Новый сосед · 50 Отзывчивый сосед · 150 Опекун квартала · 350 Страж района · 700 Герой Вроцлава · 1500 Легенда.
**Медали:** Первый шаг, Зоркий глаз (3 «видели»), Добрый сосед (2 помощи), Страж парка (3 опасности), Общительный
(3 группы), Репортёр квартала (3 объявления), Все виды (группы собак, кошек, рыб), Герой (помог найти животное).
**Рейтинг районов** — соревнование кварталов (сумма баллов жителей); видно на профиле.
**Зачем:** мотивирует отмечать «видел здесь» и помогать; уровень = доверие при присмотре (связь с уровнями в `product/sitting.md`).
