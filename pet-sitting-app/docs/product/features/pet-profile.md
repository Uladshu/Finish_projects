# Функции: Профиль питомца и здоровье

Приоритет: **Запуск** — в первой версии · **Далее** — через 1–3 мес. · **Потом** — когда есть аудитория · **Нет** — не делаем.

| Функция | Откуда | Приоритет |
|---|---|---|
| Несколько питомцев **любых видов** в одном аккаунте | Yummypets | **Запуск** |
| Медкарта: прививки, обработки, лекарства, аллергии, ветеринар + **напоминания** | DingDog, приложения ветклиник | **Запуск** (базово) |
| Журнал ухода: кормление, вес, линька (рептилии), параметры воды (аквариум) | AquaLog, AquaticLog, Fish Tank Log | Далее |
| Даты: день рождения, «день, когда взяли из приюта» | — | Далее (эмоциональный повод вернуться) |
| Посты «от лица питомца» со стикерами | Petzbe | Нет на старте (развлечение, не помощь) |
