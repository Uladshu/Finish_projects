# Функции: Потерялся / нашёлся и безопасность

Приоритет: **Запуск** — в первой версии · **Далее** — через 1–3 мес. · **Потом** — когда есть аудитория · **Нет** — не делаем.

| Функция | Откуда | Приоритет |
|---|---|---|
| Объявление «потерялся/нашёлся» для любых животных + **push всем в радиусе** 1–5 км | Finding Rover (10 миль), PiP (15 км), Nextdoor | **Запуск** |
| **Плакат в PDF с QR-кодом** одним нажатием + кнопка «поделиться в FB/WhatsApp» | PawBoost | **Запуск** (и главный канал роста: каждый плакат ведёт к нам) |
| Карта последних мест, где видели животное; отметки «видел здесь» от соседей | Nextdoor, группы FB | **Запуск** |
| Оповещение ветклиник и приютов района о потерянном животном | PiP | Далее (партнёрства) |
| **Поиск по фото** (ИИ сравнивает морды найденных и потерянных) | Finding Rover, Petco Love Lost | Потом |
| QR-адресник на ошейник → страница «я потерялся, напишите хозяину» | — | Далее |

## Поиск и сообщения (решено после прототипа)
- **Фильтр слева по виду животного** (все, собаки, кошки, птицы, грызуны/кролики, рептилии, рыбы, другие) — всё остальное подстраивается: пропажи, находки, «видели», помощь, «отдам», места (ветеринары для нужного вида); опасности только для собак/кошек.
- Затем типы, период (24 ч / 3 / 7 / 30 дней) и поиск по кличке, породе, окрасу, улице.
- **«Видел животное»** — отдельное сообщение без привязки к пропаже: точка на карте, время, фото, описание. Система показывает **совпадения**: пропавшие того же вида поблизости, и наоборот.
- **Максимум данных при пропаже:** вид, кличка, порода, пол, возраст, размер, окрас и приметы, ошейник, чип, дата и время, улица/ориентир, поведение («не догонять»), вознаграждение, **до 8 фото**.
- «Видел здесь» по пропаже — с временем, комментарием и фото.

## Жизненный цикл объявлений (решено)
- **Находка закрывает пропажу только с подтверждения владельца.** Нашедший жмёт «Я нашёл — он у меня» → владельцу уведомление;
  всем видна метка «Сообщили о находке». Владелец: «Подтверждаю — вернулся домой» (объявление закрыто, нашедшему +100 лапок)
  или «Это не моё животное» (заявка отклоняется, объявление остаётся).
- **Каждые 3 дня** (от публикации или последнего подтверждения) автору любого объявления приходит вопрос «Ещё актуально?».
  «Ещё актуально» → объявление обновляется датой подтверждения (показывается «Актуально на …», сортировка по ней).
  «Нашёлся / неактуально» → закрыто. **Нет ответа 2 дня** → объявление исчезает с карты (автор может опубликовать снова).
- Пока ждём ответа, всем видна метка «Ждём автора · исчезнет через N». Опасности обновляются подтверждениями соседей «Всё ещё там».
- Места (ветклиники, площадки) не истекают.

## «Нашёл / видел» — коротко + галерея (решено)
- Форма «нашёл / видел» — только главное: вид*, когда*, улица (необяз.), фото, **один комментарий** (внешность, ошейник,
  поведение, где сейчас, как связаться). Обязательно фото или комментарий. Карточка показывает то же самое.
- **Вкладка «Галерея»:** все найденные и замеченные животные плиткой (фото, вид, сколько времени назад, улица),
  фильтр «все / найдены / видели» + вид животного, период и поиск. Нажатие — карточка и место на карте.
  Без фото плитка окрашивается в окрас из описания (рыжий, чёрный, белый, серый, палевый, трёхцветный).

## Указание места (решено)
- В любой форме поле «Где?»: ввод улицы, района или парка с подсказками (в прототипе — офлайн-справочник улиц Вроцлава;
  в приложении — геокодер, например Nominatim/Photon на своём сервере), кнопка **«Определить меня»** (GPS телефона) или точка на карте.
- Затем всегда показываем метку на карте: её можно перетащить, улица подставляется автоматически; публикация — «Опубликовать здесь».
- GPS только по нажатию и только для этого сообщения; точный адрес дома не публикуется (см. trust-safety).

## Если браузер блокирует GPS (решено)
Никогда не тупик: при отказе открывается панель «Нет доступа к местоположению» —
- короткая инструкция **только для этого устройства** (iPhone / Android / компьютер) + «Попробовать снова»;
- **«Последнее место»** (запоминаем каждую выбранную точку в браузере);
- «Ввести адрес» и «Указать на карте»;
- в поле адреса можно **вставить ссылку Google Maps или координаты** (`51.107, 17.038`, `@lat,lng`, `!3d…!4d…`);
- **место из фото**: читаем GPS из EXIF снимка до сжатия (часто есть на Android; iPhone отдаёт, если включено «Параметры → Геопозиция» при выборе фото).
Причины блокировки: пользователь отказал, геолокация выключена в телефоне, страница не по HTTPS или во встроенном окне (предпросмотр Claude).
