# Функции: Потерялся / нашёлся и безопасность

Приоритет: **Запуск** — в первой версии · **Далее** — через 1–3 мес. · **Потом** — когда есть аудитория · **Нет** — не делаем.

## Поиск и сообщения (решено после прототипа)
- **Фильтр слева по виду животного** (все, собаки, кошки, птицы, грызуны/кролики, рептилии, рыбы, другие) — всё остальное подстраивается: пропажи, находки, «видели», помощь, «отдам», места (ветеринары для нужного вида); опасности только для собак/кошек.
- Затем типы, период (24 ч / 3 / 7 / 30 дней) и поиск по кличке, породе, окрасу, улице.
- **«Видел животное»** — отдельное сообщение без привязки к пропаже: точка на карте, время, фото, описание. Система показывает **совпадения**: пропавшие того же вида поблизости, и наоборот.
- **Максимум данных при пропаже:** вид, кличка, порода, пол, возраст, размер, окрас и приметы, ошейник, чип, дата и время, улица/ориентир, поведение («не догонять»), вознаграждение, **до 8 фото**.
- «Видел здесь» по пропаже — с временем, комментарием и фото.

## Жизненный цикл объявлений (решено)
- **Находка закрывает пропажу только с подтверждения владельца.** Нашедший жмёт «Я нашёл — он у меня» → владельцу уведомление;
  всем видна метка «Сообщили о находке». Владелец: «Подтверждаю — вернулся домой» (объявление закрыто, нашедшему +100 лапок)
  или «Это не моё животное» (заявка отклоняется, объявление остаётся).
- **Каждые 3 дня** (от публикации или последнего подтверждения) автору любого объявления приходит вопрос «Ещё актуально?».
  «Ещё актуально» → объявление обновляется датой подтверждения (показывается «Актуально на …», сортировка по ней).
  «Нашёлся / неактуально» → закрыто. **Нет ответа 2 дня** → объявление исчезает с карты (автор может опубликовать снова).
- Пока ждём ответа, всем видна метка «Ждём автора · исчезнет через N». Опасности обновляются подтверждениями соседей «Всё ещё там».
- Места (ветклиники, площадки) не истекают.
