# Функции: Сообщество

Приоритет: **Запуск** — в первой версии · **Далее** — через 1–3 мес. · **Потом** — когда есть аудитория · **Нет** — не делаем.

| Функция | Откуда | Приоритет |
|---|---|---|
| **Группы по видам** и по району («Кошатники Ołbin», «Аквариумисты Вроцлава») | Dogster (форумы под интересы пользователей) | **Запуск** |
| Вопросы и ответы с пометкой «лучший ответ»; ответы ветеринаров-партнёров | Yummypets (контент от ветеринаров) | **Запуск** (простые вопросы) / Далее (эксперты) |
| Лента района **по времени, без алгоритма вовлечения** | Petzbe | **Запуск** |
| Встречи и групповые прогулки, в т. ч. для щенков | Dogorama, Yummypets (офлайн-прогулки) | Далее |
| Фотоконкурсы («кот месяца в районе») с призами партнёров | Yummypets | Далее |
| Подписки, друзья, совместимость собак (энергия, размер, характер) | Pawmates, DOGOUT | Далее |
| Живая карта «Я гуляю» (по согласию, с зоной приватности) | Dappy Dogs, DOGOUT, Dogorama | Потом |
| Благотворительные сборы для приютов района | Petzbe (Lend a Paw) | Далее |
