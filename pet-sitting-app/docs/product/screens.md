# Экраны первой версии

| Вкладка | Что там |
|---|---|
| **Рядом** | Лента района: потерялись/нашлись (сверху), просьбы о помощи, «отдам», вопросы, опасности |
| **Карта** | Потерявшиеся, опасности, ветклиники, площадки |
| **+** | Потерялся · Нашёл · Нужна помощь · Отдам/приму · Вопрос · Опасность |
| **Группы** | Мои группы по видам и району |
| **Профиль** | Я, мои питомцы (медкарта, напоминания), мои публикации |

## Визуальный стиль (по образцу megapteka.ru, решено)
- Шрифт Montserrat 500/700; белый фон, чёрный текст, серый #707070, рамки #DADADA, фирменный красный #F63F3F.
- Поиск — «таблетка» с толстой чёрной рамкой и лупой; рядом кнопка «Фильтры» в той же форме.
- Кнопки — красные «таблетки»; второстепенные действия — красные подчёркнутые ссылки («Сбросить», «Выбрать другой город»).
- Виды животных — круглые «истории» с кольцом (выбранный — красное кольцо).
- Телефон: нижняя светло-серая полоса как у Мегаптеки — Галерея, Сообщить, **Карта (по центру, красный круг)**, Группы, Меню (профиль, мои объявления, язык, город, о приложении; счётчик ожидающих ответа). Языки на телефоне — только в меню.
- Компьютер: вкладки текстом с красным подчёркиванием.
- При первом входе — вопрос «Ваш город: Вроцлав? Да / Выбрать другой город».
- Шаги «Как найти своё животное?» — красные кружки с номерами и пунктирной линией (в галерее).
