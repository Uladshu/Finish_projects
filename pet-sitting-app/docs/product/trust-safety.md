# Доверие и безопасность

| Механика | Как |
|---|---|
| Проверка | Телефон обязательно; документ — для присмотра и для живой карты; бейджи в профиле |
| Знакомые рядом | «3 общих друга», «состоите в одной группе», объявления знакомых выше |
| Отзывы | Двусторонние, публикуются одновременно, только после реальной договорённости |
| Маленький первый шаг | Знакомство до присмотра; первые прогулки «друга животных» — вместе с хозяином |
| Защита от кражи животных | Не показывать точный адрес; пометка модератору для новых аккаунтов с интересом к породистым животным |
| Защита от мошенников | Памятка «не переводите предоплату незнакомцам за «найденное» животное» в объявлениях о потере |
| Живая карта (этап 3) | Только во время прогулки, огрубление ~200 м, зона приватности у дома, ночью только друзья, без истории маршрутов, 18+ |

Честные механики вовлечения: полезные уведомления по радиусу и интересам, без фейковой срочности.
