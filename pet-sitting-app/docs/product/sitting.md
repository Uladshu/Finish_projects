# Модуль присмотра (BlaBlaCar), этап 2

- **Объявления двух типов:** «Ищу присмотр» (питомец, даты, тип: визиты / у меня / у вас / выгул, бюджет)
  и «Могу присмотреть» (кого, где, когда, цена).
- **Цена:** фиксированная · «предложите цену» · бесплатно · обмен (баллы). Подсказка: «обычно в районе 60–90 PLN».
- **Договорённость:** отклик → чат (контакты скрыты) → до 3 встречных цен с каждой стороны →
  карточка договорённости (кто, питомец, даты, цена, способ оплаты: наличные/BLIK/бесплатно/баллы) →
  вторая сторона подтверждает → открываются телефон и адрес → знакомство → фотоотчёты → отзывы.
- **Профиль «Мой дом»:** квартира/дом/сад, дети, другие животные, курят ли, можно ли на диван.
- **Уровни:** Новичок → Проверенный → Опытный → Супер-ситтер; поздние отмены видны в профиле.

Реализовано в `db/listings.sql` и проверено (объявление → поиск → торг → договорённость → контакты).

## Функции и приоритеты

Приоритет: **Запуск** — в первой версии · **Далее** — через 1–3 мес. · **Потом** — когда есть аудитория · **Нет** — не делаем.

| Функция | Откуда | Приоритет |
|---|---|---|
| Присмотр как тип просьбы о помощи (бесплатно / «договоримся») | — | **Запуск** |
| Объявления «Ищу присмотр / Могу присмотреть», цена, торг, договорённость | BlaBlaCar | Далее (+2–3 мес.) |
| Фотоотчёты во время присмотра | Rover, Petsy | Далее |
| Двусторонние отзывы, уровни, бейджи проверки | BlaBlaCar, Rover | Далее |
| Оплата в приложении + гарантия/страховка | Rover, Petsy (Petsy Care) | Потом |
