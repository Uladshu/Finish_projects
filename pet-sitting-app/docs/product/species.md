# Модули по видам животных

| Вид | Что важно этим людям | Функции |
|---|---|---|
| **Собаки** | Прогулки, компания, отрава, присмотр, площадки | Предупреждения, встречи, площадки на карте, позже живая карта |
| **Кошки** | Потеря (часто в подъезде/подвале), визиты на время отпуска, лечение | Советы «как искать кошку», визиты соседей, ветеринары |
| **Аквариум** | Параметры воды, совместимость рыб, обмен мальками и растениями | Профиль аквариума, журнал воды, обмен, группа района |
| **Рептилии, амфибии** | Ветеринар для экзотов, кормление, линька, температура/влажность, корм-насекомые | Журнал ухода, «лечит экзотов», обмен кормом, бейдж «умею с экзотами» |
| **Птицы** | Улетевшие птицы, ветеринар-орнитолог, присмотр | Потерялся с акцентом «на дереве/на балконе», ветеринары |
| **Кролики, грызуны, хорьки** | Присмотр «вместе с клеткой», ветеринар, корм | Просьбы о помощи, «отдам/приму» клетки |

На старте один общий набор функций + **группы по видам**; специальные журналы ухода — во второй очереди.
