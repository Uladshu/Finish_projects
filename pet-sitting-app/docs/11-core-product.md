# 11 — Ядро продукта: «BlaBlaCar для присмотра за питомцами» + соцсеть владельцев

> **Главный документ продукта.** Сводит вместе 02 (концепция), 10 (соцсеть) и обсуждения о бесплатной помощи.
> Если что-то противоречит более ранним документам — действует этот.

## 1. Суть в трёх предложениях

1. Люди **сами публикуют объявления**: «Ищу, кто присмотрит за моей кошкой 10–17 августа» или
   «Могу взять собаку на выходные / покормить кошку, пока вы в отпуске».
2. Они **договариваются между собой**, как попутчики на BlaBlaCar: за цену, которую назвал автор,
   за встречную цену, **бесплатно** или **по обмену** («я посмотрю твоего кота, ты — моего»). Платформа
   не берёт комиссию и не участвует в расчётах на старте.
3. Вокруг этого — **соцсеть владельцев любых животных** в своём районе: профили питомцев, лента района,
   группы по видам, встречи, «потерялся/нашёлся», предупреждения об опасностях.

## 2. Что берём у BlaBlaCar

| У BlaBlaCar | У нас |
|---|---|
| Водитель публикует поездку: откуда, куда, когда, цена, сколько мест | **«Могу присмотреть»**: где (район/радиус), когда, каких животных, сколько, цена или «бесплатно» |
| Пассажир ищет по маршруту и дате | Владелец ищет по **датам, виду животного, расстоянию, цене** |
| Пассажир может опубликовать запрос | **«Ищу присмотр»**: питомец, даты, тип помощи, бюджет |
| Рекомендованная цена с границами | **Подсказка цены**: «обычно в вашем районе 60–90 PLN/сутки за кошку» |
| Мгновенное бронирование или по подтверждению | «Договориться» (по умолчанию) или **«Сразу подтвердить»** для опытных ситтеров |
| Предпочтения профиля: болтливость, музыка, курение, животные | **«Мой дом»**: квартира/дом/сад, дети, другие животные, курят ли, можно ли на диван, есть ли кто дома днём |
| Уровни опыта (от новичка до амбассадора) | **Уровни**: Новичок → Проверенный → Опытный → Супер-ситтер |
| Отзывы после поездки обеих сторон | **Двусторонние отзывы** после присмотра, публикуются одновременно |
| Телефон скрыт до бронирования | Контакты и точный адрес скрыты **до договорённости** |
| Отмены влияют на надёжность | **Рейтинг надёжности**: поздние отмены видны в профиле |
| Деление расходов, а не заработок | Можно указать «**бесплатно**», «**за корм / символически**» или «**обмен**» |

## 3. Объявления — сердце продукта

### Два типа объявлений

| | **«Ищу присмотр»** (владелец) | **«Могу присмотреть»** (ситтер / сосед / друг животных) |
|---|---|---|
| Кто | Питомец(ы) из профиля | Кого готов взять: виды, размеры, сколько |
| Что | У меня дома (визиты / с ночёвкой) · у вас дома · выгул · дневной присмотр | То же — какие услуги готов дать |
| Когда | Даты/время, разово или регулярно (каждый будний день) | Даты доступности или «обычно свободен по выходным» |
| Где | Район (точная точка скрыта) | Район + радиус, куда готов ходить |
| Условия | Особенности: лекарства, режим, характер | «Мой дом»: сад, дети, свои животные |
| Цена | Фикс · «предложите цену» · бесплатно · обмен | Фикс · «договоримся» · бесплатно · обмен |

### Как проходит договорённость

```
Объявление → «Откликнуться» (+ своя цена, если торг)
  → чат (контакты скрыты), можно встречное предложение по цене (до 3 раундов)
    → «Предложить договорённость» → карточка: кто, какой питомец, даты, цена, способ оплаты
      → вторая сторона «Подтверждаю» → ДОГОВОРЁННОСТЬ
        → открываются телефон и адрес · чек-лист знакомства · напоминания
          → во время присмотра: фотоотчёты
            → завершение → отзывы обеих сторон → баллы/уровень растут
```

**Карточка договорённости** — аналог подтверждённой поездки: всё, о чём договорились, в одном месте.
Её можно открыть в любой момент, на неё ссылаются при спорах. Способ оплаты — наличные, BLIK, перевод,
бесплатно или обмен; платформа только фиксирует, о чём договорились.

### Цены и торг
- Подсказка цены по району и виду животного (медиана завершённых договорённостей).
- **«Предложите цену»** — откликающийся называет свою; автор принимает или делает встречное предложение.
- **Бесплатно** и **обмен** — полноправные варианты, с отдельной иконкой и фильтром.
- **Обмен** через баллы «лапки»: присмотрел — получил баллы, нужен присмотр — расплатился баллами.

## 4. Все животные, а не только собаки

| Вид | Типичные задачи | Особенности в продукте |
|---|---|---|
| Собаки | Выгул, передержка, присмотр днём | Размер, энергия, совместимость, прогулки вместе |
| Кошки | **Визиты на дом** (покормить, лоток), передержка | Кошки плохо переносят переезд → акцент на визитах |
| Кролики, грызуны, хорьки | Передержка (в своей клетке), визиты | Клетка переезжает вместе с питомцем |
| Птицы | Передержка, визиты | Шум, свободный выгул по квартире |
| Рептилии, амфибии | Визиты: корм, температура, свет | Нужен опыт — бейдж «Умею с экзотами» |
| Рыбы, аквариумы | Визиты: корм, проверка оборудования | Простые и частые бесплатные просьбы соседям |

Ценность для «экзотов»: ситтеров для рептилий и птиц почти не найти, а **ветеринаров для экзотов**
ищут через знакомых. Рейтинг ветклиник по видам животных от сообщества — сильная и редкая функция.

## 5. Соцсеть владельцев

| Функция | Зачем |
|---|---|
| **Профиль питомца** (фото, вид, характер, медкарта) | Центр всего: из него создаются объявления, его видят в ленте |
| **Лента района** | Фото питомцев, вопросы («кто знает ветеринара для черепахи?»), объявления о встречах. Приложение открывают каждый день |
| **Группы по видам и интересам** | «Кошатники Ołbin», «Хорьки Вроцлав», «Крупные собаки — прогулки» |
| **Подписки и друзья** | Знакомые соседи → больше доверия при договорённостях |
| **Встречи и групповые прогулки** | Офлайн-знакомства — лучший источник доверия |
| **Потерялся / нашёлся** (все виды) | Оповещение всем рядом. Самая эмоциональная и вирусная функция |
| **Опасности** (отрава, стекло) | Push в радиусе 1–2 км |
| **Карта мест** | Площадки, ветклиники 24/7, ветеринары для экзотов, зоомагазины |
| **Живая карта «Я гуляю»** | Для собачников, в версии 2 (правила приватности — в 10-dog-owners-social-network) |

**Связь соцсети и присмотра:** в профиле видно «Вы знакомы: 3 общих друга, гуляли вместе 2 раза».
Объявления друзей и соседей, которых вы знаете, показываются выше.

## 6. Что «цепляет» людей: механики доверия и привычки

Принцип: **честные механики, без тёмных паттернов** — никаких фейковых срочностей и навязчивых уведомлений.

| Механика | Как работает у нас | Почему действует |
|---|---|---|
| **Доверие через проверку** (как у BlaBlaCar) | Бейджи: телефон ✓, документ ✓, фото ✓, «знаком с соседями» ✓ | Люди отдают чужому человеку члена семьи — нужны видимые причины доверять |
| **Социальное доказательство** | «Помог 14 соседям», «Отвечает за 20 минут», отзывы с фото питомцев | Доверяем тем, кому доверяют другие |
| **Знакомые рядом** | Общие друзья, совместные прогулки, «живёт в вашем районе» | Соседу доверяют больше, чем незнакомцу из другого конца города |
| **Взаимность** | Баллы «лапки», «вы помогли — вам помогут» | Люди хотят вернуть услугу; обмен снимает неловкость «бесплатно» |
| **Маленький первый шаг** | Знакомство до присмотра; первый раз — короткий визит/прогулка | Снижает страх и проверяет совместимость |
| **Прогресс и статус** | Уровни, бейджи («Кошачий друг», «Умею с экзотами», «Супер-ситтер») | Желание расти; статус в районе |
| **Эмоциональная награда** | **Фотоотчёты**: «Мурка поела и спит на подоконнике» | Владелец спокоен → рассказывает друзьям; ситтер получает благодарность |
| **Полезные триггеры** | «Рядом новая просьба на даты, когда вы свободны», «Через 2 недели ваш отпуск — найти присмотр?» | Напоминание в момент, когда действительно нужно |
| **Вложение в профиль** | Профиль питомца, медкарта, отзывы, друзья | Чем больше вложено, тем ценнее платформа и тем меньше желание уходить |
| **Безопасность как повод вернуться** | Потерялся/нашёлся, предупреждения об отраве | Причина держать приложение, даже когда присмотр не нужен |

## 7. Приоритеты: что делать в первую очередь

### Версия 1 (MVP) — то, без чего нет продукта

| # | Функция | Почему в MVP |
|---|---|---|
| 1 | Регистрация, профиль, «Мой дом», **профили питомцев всех видов** | Основа доверия и объявлений |
| 2 | **Объявления «Ищу присмотр» / «Могу присмотреть»** | Сердце продукта |
| 3 | **Поиск**: список + карта, фильтры по датам, виду животного, расстоянию, цене, «бесплатно/обмен» | Найти подходящее за минуту |
| 4 | **Отклик + торг + чат** (контакты скрыты) | Механика BlaBlaCar |
| 5 | **Карточка договорённости** + чек-лист знакомства | Ясность и защита обеих сторон |
| 6 | **Фотоотчёты** во время присмотра | Главная эмоция и причина рекомендовать |
| 7 | **Двусторонние отзывы**, бейджи проверки, рейтинг надёжности | Доверие |
| 8 | **Push-уведомления о подходящих объявлениях рядом** | Ликвидность: объявление не должно висеть без ответа |
| 9 | **Потерялся / нашёлся** | Вирусность и польза для всех |
| 10 | Жалобы и модерация | Безопасность |

### Версия 1.1 (через 1–2 месяца после запуска)
- Лента района и группы по видам.
- Встречи и групповые прогулки.
- Карта мест + ветеринары для экзотов.
- Предупреждения об опасностях.
- Баллы «лапки» для обмена.
- Регулярные договорённости («каждый будний день выгул в 13:00»).

### Версия 2
- Живая карта «Я гуляю».
- Безопасная оплата в приложении (BLIK/карта) + гарантия — платная опция.
- Продвижение объявлений, премиум-профиль, карточки местного бизнеса.

## 8. Экраны MVP (нижнее меню)

| Вкладка | Что там |
|---|---|
| **Главная** | Объявления рядом (две ленты: «Нужна помощь» / «Предлагают помощь»), кнопка «+ Объявление», мои активные договорённости |
| **Карта** | Объявления и (в v1.1) места/опасности на карте района |
| **+** | Создать объявление: 4 шага — питомец → что нужно → когда → цена (фикс / предложите / бесплатно / обмен) |
| **Сообщения** | Чаты по объявлениям, предложения цены, карточки договорённостей |
| **Профиль** | Я, мои питомцы, «Мой дом», отзывы, уровень, баллы, проверка документа |

## 9. Правила и безопасность (кратко)

- Публиковать объявления и откликаться могут только пользователи с подтверждённым телефоном, 18+.
- Первый присмотр нового пользователя — только после знакомства (чек-лист в карточке договорённости).
- В правилах: запрет на перепродажу и разведение чужих животных, проверка прививок у собак,
  что делать при болезни и побеге.
- Подозрительные шаблоны (просьбы о предоплате незнакомцу, много откликов на породистых собак от
  нового аккаунта) — автоматическая пометка модератору.
- Юридически платформа — доска объявлений с инструментами договорённости. Договор об услуге — между
  пользователями (см. 06 и 09, раздел «Польская специфика»).

## 10. Метрики, по которым видно, что ядро работает

| Метрика | Цель (стартовый район, 6 мес.) |
|---|---|
| Доля объявлений «Ищу присмотр», получивших отклик за 24 ч | 70 %+ |
| Доля объявлений, закончившихся договорённостью | 40 %+ |
| Доля договорённостей с фотоотчётом | 80 %+ |
| Доля договорённостей с отзывом | 60 %+ |
| Повторные договорённости (с тем же или другим человеком) | 30 %+ |
| Доля бесплатных и обменных договорённостей | наблюдаем: если > 70 %, монетизация через комиссию не подойдёт → членство/премиум |
| Пользователи, открывающие приложение раз в неделю (соцсеть) | 40 %+ |
