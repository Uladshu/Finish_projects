# 03 — Бизнес-модель

## 1. Почему бесплатно на старте

Маркетплейс ценен ровно настолько, насколько в нём есть выбор. В первые месяцы у нас нет ни отзывов,
ни бренда — брать деньги не за что. Бесплатность решает три задачи:

1. **Холодный старт** — ситтеры регистрируются без риска; владельцы пробуют без риска.
2. **База отзывов** — отзывы и рейтинг накапливаются только внутри платформы; это главный «замок»,
   удерживающий ситтеров от ухода в офлайн, когда появится комиссия.
3. **Обучение** — мы видим реальные сценарии, цены, отмены, конфликты и строим монетизацию на данных.

### Правила бесплатного периода (публично)
- 0 % комиссии, 0 ₽ за размещение и отклики, без ограничений на число заявок.
- Оплата — напрямую между владельцем и ситтером (наличные/перевод), платформа в расчётах не участвует.
- Обещание в оферте и на сайте: **«базовое размещение и поиск навсегда останутся бесплатными»**;
  платными в будущем станут только дополнительные сервисы (безопасная сделка, гарантия, продвижение).
  Это снимает страх «заманят, а потом начнут брать деньги».
- Первые 500 ситтеров получают статус **«Основатель»**: пожизненный бейдж + сниженная комиссия
  (например, 5 % вместо 10 %) — стимул прийти рано.

### Когда переходить к монетизации (триггеры, а не даты)
- в городе 300+ активных ситтеров и 500+ завершённых бронирований в месяц;
- повторные бронирования ≥ 25–30 %;
- средний рейтинг ≥ 4,7 и низкая доля инцидентов;
- опрос: ≥ 40 % владельцев готовы платить за гарантию/безопасную оплату.

## 2. Модели монетизации (этап 2+)

| # | Источник | Механика | Ориентир |
|---|---|---|---|
| 1 | **Безопасная сделка** (основной) | Владелец платит в приложении, деньги замораживаются и уходят ситтеру после завершения. Сервисный сбор с владельца + комиссия с ситтера | 8–10 % с владельца + 5–10 % с ситтера (итого 13–20 % take rate) |
| 2 | **Гарантия ZooДом** | Покрытие ветрасходов до N ₽, замена ситтера при отказе, поддержка 24/7 — только для бронирований, оплаченных в приложении | входит в сбор; формируем гарантийный фонд 1–2 % GMV или партнёрство со страховой |
| 3 | **Продвижение анкет** | Поднятие в выдаче, бейдж «Топ», показ в рассылке | 199–799 ₽/нед. |
| 4 | **PRO-подписка ситтера** | Расширенная статистика, приоритет поддержки, персональная ссылка, онлайн-визитка | 299–499 ₽/мес. |
| 5 | **B2B — зоогостиницы, грумеры, кинологи** | Профиль бизнеса, онлайн-запись, CRM | 1 500–5 000 ₽/мес. или комиссия |
| 6 | **Партнёрства** | Корма, ветклиники, зоомагазины, страхование питомцев — промокоды, CPA | 3–10 % с продаж / CPA |
| 7 | **Обучение и сертификация ситтеров** | Онлайн-курс «первая помощь животным», платный значок «Сертифицирован» | 990–2 990 ₽ |

Чего **не делаем**: платные отклики для ситтеров (как у Profi.ru) — это убивает доверие и качество
предложения на нишевом рынке.

## 3. Юнит-экономика (после включения безопасной сделки)

Единица — одно оплаченное бронирование.

| Показатель | Значение | Комментарий |
|---|---|---|
| Средняя длительность | 6 суток | сочетание отпусков и коротких поездок |
| Средняя цена суток | 1 200 ₽ | город-миллионник |
| **GMV бронирования** | **7 200 ₽** | |
| Take rate | 15 % | 10 % владелец + 5 % ситтер |
| **Выручка платформы** | **1 080 ₽** | |
| Эквайринг и выплаты | −2,5 % GMV = −180 ₽ | ЮKassa / CloudPayments / bePaid |
| Гарантийный фонд | −1,5 % GMV = −108 ₽ | |
| Поддержка и модерация | −80 ₽ | |
| **Маржинальный доход** | **≈ 710 ₽** | ~66 % выручки |

| Клиентская экономика | Значение |
|---|---|
| Бронирований на владельца в год | 2,5 |
| Средний срок жизни клиента | 2,5 года |
| **LTV владельца** | 710 × 2,5 × 2,5 ≈ **4 400 ₽** |
| Допустимый CAC (LTV/CAC ≥ 3) | ≤ 1 500 ₽ |
| Ожидаемый CAC при смеси каналов (SEO, рефералка, таргет) | 600–1 200 ₽ |

Выгул и визиты: чек ниже (500–800 ₽), но частота выше (8–20 раз в месяц у регулярных клиентов) —
это хорошо выравнивает сезонность.

## 4. Финансовая модель (базовый сценарий, один город → 5 городов)

Упрощённо, в ₽, без налогов. Год 1 — бесплатный период.

| | Год 1 (бесплатно) | Год 2 (монетизация с 2 кв.) | Год 3 |
|---|---|---|---|
| Городов | 1–2 | 3–5 | 8–10 |
| Активных ситтеров (конец года) | 600 | 3 000 | 10 000 |
| Завершённых бронирований / год | 4 000 (вне приложения) | 25 000 (из них 60 % через оплату) | 90 000 (75 % через оплату) |
| GMV через платформу | 0 | ≈ 110 млн | ≈ 490 млн |
| Выручка (take rate 15 % + доп. сервисы) | 0 | ≈ 18 млн | ≈ 80 млн |
| Расходы: команда | 9–14 млн | 25–35 млн | 45–60 млн |
| Расходы: маркетинг | 2–4 млн | 10–15 млн | 20–30 млн |
| Расходы: инфраструктура, SMS, сервисы | 0,5–1 млн | 2–3 млн | 5–7 млн |
| **Результат** | **−12…−19 млн** | **−20…−35 млн** | **≈ −2…+15 млн** (выход в безубыток) |

Варианты сокращения расходов: старт силами 2–3 основателей + фрилансеры (команда год 1 → 3–5 млн),
no-code админка, органический рост через сообщества. Тогда «бесплатный год» обходится в 4–8 млн ₽.

## 5. Сценарии

| Сценарий | Что происходит | Год 3 GMV |
|---|---|---|
| Пессимистичный | Медленный рост ситтеров, сильный увод в офлайн | 100–150 млн ₽ — нишевый проект, нужна дешёвая команда |
| Базовый | Как в таблице | ≈ 500 млн ₽ |
| Оптимистичный | Вирусность в соцсетях, партнёрство с крупной сетью зоомагазинов/ветклиник | 1+ млрд ₽ |

## 6. Финансирование

1. **Bootstrapping / FFF** — до MVP и первых 200 ситтеров (1,5–4 млн ₽).
2. **Гранты** — в РФ: Фонд содействия инновациям («Студенческий стартап», «Старт»); в РБ: БИП, гранты Парка высоких технологий / региональные программы. Проверить актуальные условия.
3. **Ангелы / pre-seed** — после 3–6 месяцев метрик в первом городе (повторные бронирования, рост ситтеров).
4. **Стратегический партнёр** — зоо-ритейл, ветсети, кормовые бренды, классифайды, банковские экосистемы.
