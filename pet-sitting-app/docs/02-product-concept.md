# 02 — Концепция продукта и MVP

## 1. Ценностное предложение

| Для кого | Боль | Что даём |
|---|---|---|
| **Владелец** | «Страшно оставить питомца чужому», «зоогостиница — клетка и стресс», «знакомые подвели в последний момент» | Проверенные ситтеры рядом, отзывы, знакомство до передержки, ежедневные фото/видео, замена при отказе |
| **Ситтер** | «Люблю животных и хочу подработать, но где искать клиентов?», «Avito — много спама и платные услуги» | Бесплатная анкета, поток клиентов рядом, календарь, рейтинг, который работает как портфолио |
| **Зоогостиница / грумер / кинолог** (этап 2) | Дорогое привлечение клиентов | Профиль бизнеса, онлайн-заявки, отзывы |

## 2. Персонажи

2. **Игорь, 45** — две кошки, частые командировки на 2–3 дня. Нужны визиты на дом: покормить, убрать лоток, прислать фото.
3. **Мария, 22, студентка-ветеринар** — хочет подрабатывать передержкой у себя дома в свободное время.
4. **Ольга, 58, на пенсии, свой дом** — держала собак всю жизнь, ищет занятие и доход, берёт собак на время.
5. **Зоогостиница «Лапа»** — 20 вольеров, хочет заполнять их вне сезона.

## 4. MVP — что входит, а что нет

### Входит (v1.0, 3–4 месяца разработки)

**Общее**
- Регистрация по телефону (SMS/OTP) или через Google/Apple/Telegram.
- Две роли в одном аккаунте: владелец и ситтер (можно переключаться).
- Выбор города, геопозиция, язык RU (позже BY/EN/KZ).

**Владелец**
- Профили питомцев: вид, порода, возраст, вес, характер, прививки (фото ветпаспорта), особенности (лекарства, аллергии, страхи).
- Поиск ситтеров: по услуге, датам, карте/расстоянию, виду и размеру животного, наличию двора/детей/других животных, рейтингу.
- Карточка ситтера: фото жилья, описание, опыт, цены, календарь доступности, отзывы, бейджи верификации.
- Заявка на бронирование → подтверждение ситтером.
- Чат с ситтером (текст, фото), договорённость о знакомстве («meet & greet»).
- Ежедневный отчёт: фото/видео + короткая отметка «покормлен / погулял / настроение».
- Отзыв и оценка после завершения (двусторонние отзывы — ситтер тоже оценивает владельца).

**Ситтер**
- Анкета: услуги, цены, условия, фото, кого принимает (размеры, виды), макс. число животных.
- Календарь занятости.
- Входящие заявки, принять/отклонить, чат.
- Верификация: фото документа + селфи (ручная проверка модератором на старте).

**Админка / модерация**
- Проверка анкет и документов, блокировка, жалобы, просмотр споров.
- Базовая аналитика: регистрации, анкеты, заявки, завершённые передержки.

### Не входит в MVP (сознательно)
- Онлайн-оплата и комиссия (стороны рассчитываются напрямую — сервис бесплатный).
- Страхование, гарантийный фонд.
- Видеозвонки, GPS-трекинг прогулок (этап 2).
- Подписки, продвижение анкет.
- Зоогостиницы как отдельный тип бизнеса.

## 5. Ключевые сценарии (user flow)

### Владелец ищет передержку
```
Открыл приложение → выбрал «Передержка» + даты + питомца
→ список/карта ситтеров рядом (фильтры)
→ карточка ситтера → «Написать» / «Запросить бронь»
→ чат: вопросы, договорились о знакомстве
→ ситтер подтвердил → бронь «Подтверждена»
→ в день начала: статус «Идёт», ежедневные фотоотчёты
→ завершение → оценка и отзыв (обе стороны)
```

### Ситтер начинает работать
```
Регистрация → «Стать ситтером» → анкета (услуги, цены, фото жилья)
→ верификация документа → модерация (≤ 24 ч)
→ анкета в поиске → получил заявку (push) → чат → подтвердил
→ во время передержки отправляет отчёты → получает отзыв → растёт в выдаче
```

### Статусы бронирования
```
requested → accepted → in_progress → completed → reviewed
        ↘ declined     ↘ cancelled_by_owner / cancelled_by_sitter
                         ↘ disputed
```

## 6. Как ранжировать ситтеров (на старте)

Формула выдачи (простая и прозрачная, позже — ML):
`score = расстояние (вес 0,35) + рейтинг (0,25) + число завершённых передержек (0,15) + скорость ответа (0,10) + полнота анкеты и верификация (0,10) + новизна (0,05, буст новым ситтерам)`

## 7. Метрики продукта

| Метрика | Цель через 6 мес. после запуска в городе |
|---|---|
| Активные верифицированные ситтеры | 300+ |
| Ситтеров в радиусе 3 км от среднего владельца | 5+ |
| Конверсия поиск → заявка | 8–12 % |
| Доля заявок, принятых ситтером | 60 %+ |
| Время первого ответа ситтера | < 1 ч (медиана) |
| Завершённые бронирования / мес. | 500+ |
| Средний рейтинг | 4,7+ |
| Повторные бронирования владельцев за 6 мес. | 30 %+ |
| NPS | 50+ |

## 8. Дизайн-принципы

- Доверие на каждом экране: бейджи верификации, реальные фото, количество отзывов, «отвечает за ~20 мин».
- Минимум шагов до первой заявки (≤ 3 экрана после выбора услуги).
- Тёплый, «домашний» визуальный стиль; крупные фото животных.
- Доступность: читаемые шрифты для старшей аудитории ситтеров (персонаж Ольга).
