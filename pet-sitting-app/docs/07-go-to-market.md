# 07 — Выход на рынок (Go-to-Market)

## 1. Стратегия: «сначала ситтеры, потом владельцы, один город за раз»

Маркетплейс ломается, если владелец открыл приложение и рядом никого нет. Поэтому:

1. **Город-плацдарм**: один город (Минск, Казань, Екатеринбург, Новосибирск и т. п.), где у команды есть
   связи и где нет сильного конкурента. Москву и СПб — позже: дорогой маркетинг и уже есть игроки.
2. **Предложение до спроса**: 150–200 верифицированных ситтеров до открытия приложения для владельцев.
3. **Плотность, а не охват**: лучше 5 ситтеров в каждом из 20 районов, чем 100 в одном.

## 2. Привлечение ситтеров (бесплатно для них — это главный аргумент)

| Канал | Тактика |
|---|---|
| Ветеринарные колледжи и академии | Партнёрство, подработка для студентов, лекция «как зарабатывать на любви к животным» |
| Волонтёры приютов и зоозащитные сообщества | Передержка — их привычная деятельность; бейдж «Волонтёр», часть будущей комиссии — приютам |
| Кинологи, грумеры, хэндлеры | Дополнительный канал клиентов |
| Авито/Kufar/Profi — ситтеры, уже дающие объявления | Прямое приглашение: бесплатная анкета, отзывы, без платных откликов |
| Чаты районов и собачников в Telegram/VK | Посты, конкурс «Первые 100 ситтеров города» |
| Пенсионеры и мамы в декрете с опытом содержания животных | Таргет VK/OK, «подработка рядом с домом» |

Стимулы: статус «Основатель» (пожизненный бейдж + льготная комиссия в будущем), бесплатная фотосессия
для анкеты, онлайн-курс «Первая помощь животным» бесплатно.

## 3. Привлечение владельцев

| Канал | Тактика | Ожидаемая стоимость |
|---|---|---|
| SEO | Веб-страницы «Передержка собак в [районе]», «Передержка кошек [город]», анкеты ситтеров индексируются | низкая, долгосрочная |
| Сарафан и рефералка | «Приведи друга» — бонусы (в бесплатный период — розыгрыши кормов/игрушек от партнёров) | 200–500 ₽ |
| Ветклиники и зоомагазины | Стойки/флаеры с QR, промокоды партнёров, «рекомендовано клиникой X» | 300–700 ₽ |
| Собачьи площадки, выставки, кинологические клубы | Офлайн-активации, мерч (пакеты для выгула с QR) | 300–800 ₽ |
| Таргет (VK, Яндекс Директ, Telegram Ads) | Перед сезоном: май–июнь, ноябрь–декабрь; гео-таргет на районы с ситтерами | 500–1 500 ₽ |
| Контент: TikTok / Reels / Shorts / Дзен | Фотоотчёты счастливых питомцев (с согласия), истории ситтеров | органика |
| Блогеры-зоо (микро) | Обзоры, промокоды | 300–1 000 ₽ |
| Турагентства, отели, авиа-тематика | «Едете в отпуск? Питомец — к нам» | партнёрство |

## 4. Сезонный календарь

| Период | Действие |
|---|---|
| Февраль–апрель | Набор ситтеров к лету |
| Май–август | Пик спроса на передержку, максимум маркетинга для владельцев |
| Сентябрь–октябрь | Выгул и визиты (работающие владельцы), B2B-партнёрства |
| Ноябрь–январь | Новогодний пик: кампания «Новый год без забот о питомце» |

## 5. Воронка и целевые метрики (город, 6 мес. после запуска)

```
Установки 20 000
 → Регистрации 10 000 (50 %)
   → Добавили питомца 6 000 (60 %)
     → Отправили заявку 1 800 (30 %)
       → Бронь подтверждена 1 100 (60 %)
         → Завершено с отзывом 900 (80 %)
           → Повторная бронь за 6 мес. 300 (33 %)
```

Еженедельный дашборд: новые ситтеры (верифицированные), ситтеры в радиусе 3 км, заявки,
доля принятых, медиана времени ответа, завершённые брони, рейтинг, жалобы/инциденты.

## 6. Сообщество

- Telegram-чат ситтеров города (взаимопомощь, замены, правила).
- Ежемесячный «Ситтер месяца» с призами от партнёров.
- Программа «Приют-партнёр»: в будущем 1 % комиссии — в местные приюты; на старте — сбор кормов.

## 7. Масштабирование на новый город (плейбук)

1. Анализ: население, доля владельцев, конкуренты, цены.
2. Нанять/найти городского комьюнити-менеджера.
3. 4–6 недель набора ситтеров (цель 150) по каналам из раздела 2.
4. Открыть город для владельцев, запустить SEO-страницы и локальный таргет.
5. Через 3 месяца — оценка по метрикам ликвидности; решение о маркетинговом бюджете.
