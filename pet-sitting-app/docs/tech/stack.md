# Технологии

| Слой | Выбор |
|---|---|
| Клиент | **PWA на Next.js** (быстро, без сторов) → позже React Native (Expo) или Flutter |
| Бэкенд | **Supabase** (PostgreSQL + PostGIS, Auth, Storage, Realtime), регион **Frankfurt** (RODO) |
| Карта | MapLibre + OpenStreetMap (бесплатно) |
| Push | Web Push / FCM / APNs; выбор получателей по радиусу через PostGIS |
| Вход | Email-ссылка, Google, Apple (SMS в ЕС дорогие) |
| Плакаты | Генерация PDF с QR на сервере (Edge Function) |
| Оплата (этап 3) | Stripe Connect (BLIK, Przelewy24) |
| Языки | PL, UK, EN (+ RU) |
| Аналитика / ошибки | PostHog, Sentry |

Стоимость инфраструктуры на старте: ≈ 100–1 000 PLN/мес.

**База данных** (`db/`, проверена на PostgreSQL 16 + PostGIS):
- `schema.sql` — пользователи, питомцы всех видов, ситтеры, бронирования, чат, отзывы, верификация;
- `social.sql` — прогулки и живая карта с приватностью, друзья, места, опасности, потерялся/нашёлся, баллы;
- `listings.sql` — объявления присмотра, отклики, торг, договорённости, скрытые контакты, подсказка цены.

**Чего не хватает в БД для соцсети-первой версии** (добавить при разработке): группы и участники,
посты ленты (типы: вопрос / помощь / отдам / фото), комментарии, генерация плакатов,
журналы ухода (аквариум, рептилии).
