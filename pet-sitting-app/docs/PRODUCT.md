# Продукт: соседская соцсеть помощи для владельцев животных

> Стратегия, рынок, деньги, право — в [STRATEGY.md](STRATEGY.md). Схема БД — в `db/`.

## 1. Концепция

**Не «Instagram для питомцев», а «соседи помогают соседям».** Фото питомцев люди и так публикуют в
Instagram и Facebook — там нас не победить. Побеждаем **полезностью рядом с домом**:

1. **Потерялся / нашёлся** — главный повод прийти и рассказать другим.
2. **Просьбы о помощи** — «кто покормит кота в выходные», «подвезите к ветеринару», «отдам переноску».
   Присмотр — один из типов просьбы с первого дня, бесплатно или «договоримся».
3. **Группы по видам** — собачники, кошатники, аквариумисты, террариумисты, птицы, грызуны: знания и обмен.
4. **Безопасность района** — отрава, опасности, ветклиники 24/7 на карте.

Второй этап — **модуль присмотра как BlaBlaCar**: объявления «Ищу присмотр / Могу присмотреть», цена,
торг, договорённость (раздел 4).

```
Потерялся/нашёлся, группы, помощь → люди приходят и остаются → знакомы с соседями, есть отзывы
→ доверяют друг другу присмотр → бесплатный обмен → платный присмотр и сервисы
```

### Чего не делаем
- Конкуренцию с Instagram за красивые фото и блогеров.
- Переводчики «мяуканья» и прочие игрушки — не дают пользы.
- Бесконечную ленту с алгоритмом вовлечения.

## 3. Модули по видам животных

| Вид | Что важно этим людям | Функции |
|---|---|---|
| **Собаки** | Прогулки, компания, отрава, присмотр, площадки | Предупреждения, встречи, площадки на карте, позже живая карта |
| **Кошки** | Потеря (часто в подъезде/подвале), визиты на время отпуска, лечение | Советы «как искать кошку», визиты соседей, ветеринары |
| **Аквариум** | Параметры воды, совместимость рыб, обмен мальками и растениями | Профиль аквариума, журнал воды, обмен, группа района |
| **Рептилии, амфибии** | Ветеринар для экзотов, кормление, линька, температура/влажность, корм-насекомые | Журнал ухода, «лечит экзотов», обмен кормом, бейдж «умею с экзотами» |
| **Птицы** | Улетевшие птицы, ветеринар-орнитолог, присмотр | Потерялся с акцентом «на дереве/на балконе», ветеринары |
| **Кролики, грызуны, хорьки** | Присмотр «вместе с клеткой», ветеринар, корм | Просьбы о помощи, «отдам/приму» клетки |

На старте один общий набор функций + **группы по видам**; специальные журналы ухода — во второй очереди.

## 4. Модуль присмотра (BlaBlaCar) — этап 2

- **Объявления двух типов:** «Ищу присмотр» (питомец, даты, тип: визиты / у меня / у вас / выгул, бюджет)
  и «Могу присмотреть» (кого, где, когда, цена).
- **Цена:** фиксированная · «предложите цену» · бесплатно · обмен (баллы). Подсказка: «обычно в районе 60–90 PLN».
- **Договорённость:** отклик → чат (контакты скрыты) → до 3 встречных цен с каждой стороны →
  карточка договорённости (кто, питомец, даты, цена, способ оплаты: наличные/BLIK/бесплатно/баллы) →
  вторая сторона подтверждает → открываются телефон и адрес → знакомство → фотоотчёты → отзывы.
- **Профиль «Мой дом»:** квартира/дом/сад, дети, другие животные, курят ли, можно ли на диван.
- **Уровни:** Новичок → Проверенный → Опытный → Супер-ситтер; поздние отмены видны в профиле.

Реализовано в `db/listings.sql` и проверено (объявление → поиск → торг → договорённость → контакты).

## 5. Доверие и безопасность

| Механика | Как |
|---|---|
| Проверка | Телефон обязательно; документ — для присмотра и для живой карты; бейджи в профиле |
| Знакомые рядом | «3 общих друга», «состоите в одной группе», объявления знакомых выше |
| Отзывы | Двусторонние, публикуются одновременно, только после реальной договорённости |
| Маленький первый шаг | Знакомство до присмотра; первые прогулки «друга животных» — вместе с хозяином |
| Защита от кражи животных | Не показывать точный адрес; пометка модератору для новых аккаунтов с интересом к породистым животным |
| Защита от мошенников | Памятка «не переводите предоплату незнакомцам за «найденное» животное» в объявлениях о потере |
| Живая карта (этап 3) | Только во время прогулки, огрубление ~200 м, зона приватности у дома, ночью только друзья, без истории маршрутов, 18+ |

Честные механики вовлечения: полезные уведомления по радиусу и интересам, без фейковой срочности.

## 7. Технологии

| Слой | Выбор |
|---|---|
| Клиент | **PWA на Next.js** (быстро, без сторов) → позже React Native (Expo) или Flutter |
| Бэкенд | **Supabase** (PostgreSQL + PostGIS, Auth, Storage, Realtime), регион **Frankfurt** (RODO) |
| Карта | MapLibre + OpenStreetMap (бесплатно) |
| Push | Web Push / FCM / APNs; выбор получателей по радиусу через PostGIS |
| Вход | Email-ссылка, Google, Apple (SMS в ЕС дорогие) |
| Плакаты | Генерация PDF с QR на сервере (Edge Function) |
| Оплата (этап 3) | Stripe Connect (BLIK, Przelewy24) |
| Языки | PL, UK, EN (+ RU) |
| Аналитика / ошибки | PostHog, Sentry |

Стоимость инфраструктуры на старте: ≈ 100–1 000 PLN/мес.

**База данных** (`db/`, проверена на PostgreSQL 16 + PostGIS):
- `schema.sql` — пользователи, питомцы всех видов, ситтеры, бронирования, чат, отзывы, верификация;
- `social.sql` — прогулки и живая карта с приватностью, друзья, места, опасности, потерялся/нашёлся, баллы;
- `listings.sql` — объявления присмотра, отклики, торг, договорённости, скрытые контакты, подсказка цены.

**Чего не хватает в БД для соцсети-первой версии** (добавить при разработке): группы и участники,
посты ленты (типы: вопрос / помощь / отдам / фото), комментарии, генерация плакатов,
журналы ухода (аквариум, рептилии).

| Пользователи, заходящие раз в неделю | 40 %+ |
