# ZooДом — приложение передержки домашних животных

> Рабочее название. Маркетплейс, который соединяет владельцев собак и кошек с проверенными
> ситтерами (частными лицами) и зоогостиницами: передержка, выгул, визиты на дом.
> **На старте сервис полностью бесплатный для всех пользователей** — и для владельцев, и для ситтеров.

## Идея в одном абзаце

Каждый раз, уезжая в отпуск, в командировку или в больницу, владелец питомца решает одну и ту же
задачу: «кому оставить собаку/кошку, чтобы с ней ничего не случилось». Сейчас это решается через
знакомых, чаты в Telegram/VK, Avito и зоогостиницы — без гарантий, без отзывов, без фотоотчётов.
ZooДом даёт одно место, где можно за 5 минут найти рядом с домом человека с отзывами и проверенными
документами, договориться в чате, получать фото/видео каждый день и оставить отзыв.

## Ключевые решения (TL;DR)

1. **Модель** — двусторонний маркетплейс (owner ↔ sitter), как Rover / Pawshake / Holidog.
2. **Старт** — 0 % комиссии, 0 ₽ подписки, без онлайн-оплаты: оплату стороны проводят напрямую.
   Цель первых 6–12 месяцев — не выручка, а **ликвидность** (в каждом районе города есть 5+ ситтеров
   с отзывами) и **база отзывов**, которая удерживает пользователей на платформе.
3. **Монетизация (после product-market fit)** — безопасная сделка с комиссией 10–15 %, гарантия/страховка,
   продвижение анкет ситтеров, B2B-тариф для зоогостиниц. Бесплатное размещение остаётся навсегда.
4. **Гео** — один город-плацдарм (например, Минск или один город-миллионник РФ), затем масштабирование.
5. **Технологии для MVP** — Flutter или React Native (Expo) + Supabase (PostgreSQL, Auth, Storage,
   Realtime) → запуск за 3–4 месяца командой 2–4 человека и бюджетом от ~1,5–4 млн ₽.
