# Соседская соцсеть для владельцев животных

Бесплатная локальная соцсеть помощи для владельцев любых животных: потерялся/нашёлся, просьбы о помощи,
группы по видам, предупреждения, карта ветклиник. Присмотр — сначала как просьба о помощи, затем модуль
в стиле BlaBlaCar. Старт — Вроцлав, один район.

Карта всех материалов — [CLAUDE.md](CLAUDE.md). Решения — [docs/decisions.md](docs/decisions.md).
