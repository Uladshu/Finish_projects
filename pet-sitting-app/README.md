# Соседская соцсеть для владельцев животных (рабочее название — подобрать латинское)

Бесплатная локальная соцсеть помощи для владельцев **любых** животных: потерялся/нашёлся с оповещением
соседей, просьбы о помощи, «отдам/приму», группы по видам (собаки, кошки, аквариум, рептилии, птицы, грызуны),
предупреждения об опасностях, карта ветклиник. Присмотр (ситтинг) — сначала как бесплатная просьба о помощи,
затем модуль в стиле BlaBlaCar: объявления, цена или бесплатно, торг, договорённость.

**Старт:** Польша → Вроцлав → один район (кандидат — вокруг Park Szczytnicki), затем расширение кругами.

SQL применяется по порядку: `schema.sql` → `social.sql` → `listings.sql` (Supabase / PostgreSQL 16 + PostGIS).
