# Finish_projects

Проекты:
- `pet-sitting-app/` — соседская соцсеть помощи для владельцев животных + присмотр (Польша, Вроцлав).
  Индекс и правила: `pet-sitting-app/CLAUDE.md` — читать первым при любой задаче по проекту.

## Правила экономии контекста (для всех проектов)
- Не читать файлы целиком «на всякий случай». Сначала индекс (`CLAUDE.md` проекта), потом только нужный файл.
- Внутри больших файлов (SQL, код) — сначала `grep -n`, потом читать только найденный диапазон строк.
- Не создавать новых длинных документов. Новая информация — в подходящий маленький файл (≤ ~60 строк);
  нет подходящего — создать новый маленький файл и добавить строку в индекс.
- Пользователь общается на русском; документация на русском.
